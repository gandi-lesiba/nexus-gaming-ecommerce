# Nexus Gaming E-commerce Platform

A responsive, front-end e-commerce website for a gaming company featuring modern web technologies and interactive shopping experience.

## Features
- Fully responsive design for all devices
- Interactive product catalog and shopping cart
- LocalStorage API for cart persistence
- Modern UI/UX principles
- Cross-browser compatibility

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage API
- Responsive Web Design
